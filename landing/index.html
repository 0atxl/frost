Before you start

Linux desktop · Python 3 with PyGObject · GIO/GVfs and user D-Bus. The AUR package installs system dependencies. The Linux archive includes Node.js; source installs need a supported Node.js ≥22.13.

Other Arch Linux installation options

With paru:

paru -S frost
frost

Without an AUR helper, review the PKGBUILD and build as your normal user: 

git clone https://aur.archlinux.org/frost.git
cd frost
makepkg -si
frost

Install from source 
git clone https://github.com/0atxl/frost.git
cd frost
npm ci
npm run build
npm start

Requires a supported Node.js release ≥22.13, npm, and the desktop dependencies below.

Desktop dependencies and first launch

On Ubuntu or Debian:

sudo apt install python3-gi gir1.2-glib-2.0 gvfs gvfs-backends

On Arch Linux:

sudo pacman -S python python-gobject glib2 gvfs

Run Frost as your normal desktop user. On first launch, create an access key. Keep the process running while you use Frost. File operations affect the files on your computer.

A few practical details.

Does Frost upload my files?

No. The local service listens on your computer's loopback address. Browsing, searching, and previews happen locally.

Can I use it on Windows or macOS?

The browser interface can be shared across platforms. The current release uses Linux desktop integrations; Windows and macOS need their own integrations before they are supported.

Does the access key encrypt my files?

No. It locks access through Frost. Your files and operating-system permissions stay as they are.
