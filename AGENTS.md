# Project instructions

## Tests

Do not run tests unless the user explicitly asks for or authorizes them in the current task. A request to implement, fix, or review something is not permission to run tests. This includes automated test suites and manual browser testing.

You may suggest relevant tests, but never execute them without explicit user authorization. Do not run validation checks, such as type checking or linting, as a substitute for tests without permission.

Authorization to run or inspect GitHub Actions applies only to remote CI. It does not authorize local tests or validation commands.
